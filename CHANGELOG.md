# Changelog

All notable changes to **eY OS** will be documented in this file.

This project follows a milestone-based versioning approach.

# v0.3.0 - Backend Foundation (2026-07-25)

## Added

### Backend
- Express API server
- TypeScript backend architecture
- Shared configuration management
- Environment variable validation
- Root development workspace

### Google Integration
- Google OAuth 2.0 authentication
- Automatic access token refresh
- Google Smart Device Management (SDM) integration

### Smart Home
- Live Google Nest thermostat integration
- Temperature monitoring
- Humidity monitoring
- Thermostat mode
- Eco mode
- Heating status
- Online status

### Frontend
- Nest Quick Status card
- Live backend integration
- Shared frontend/backend development startup (`npm run dev`)
- Portable Node.js launcher (`start-ey-os.bat`)

### Project
- Updated README
- Improved project structure
- Backend architecture documentation
